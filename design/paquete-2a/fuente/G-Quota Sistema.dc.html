G-Quota · Sistema de diseño
Dirección 2a Contable. Hay dos tipos de tokens. Los de marca los configura cada negocio en Mi marca y la app los calcula. Los del sistema son fijos para todos los negocios. Todo se define como variables CSS y se conecta a Tailwind.
Regla 1
La marca va en el marco
Logo, ítem activo del menú, botón principal, franja del comprobante y encabezado de las tarjetas. Nunca en estados, barras de datos ni cifras.
Regla 2
El contraste lo calcula la app
Texto sobre la marca: blanco o tinta, el que tenga más contraste. Si la marca se usa como texto sobre blanco y no llega a 4,5:1, se oscurece hacia la tinta hasta llegar.
Regla 3
Estado = ícono + etiqueta
Los colores de estado son fijos. Cada estado tiene su forma de ícono y su palabra, así que se distinguen aunque la marca sea verde o roja, y también sin color.

// marca.ts: se llama al cargar el negocio
export function aplicarMarca(principal: string, acento: string) {
  const r = document.documentElement.style;
  r.setProperty('--marca', principal);
  r.setProperty('--marca-sobre', sobre(principal));        // blanco o tinta
  r.setProperty('--marca-texto', comoTexto(principal));    // ≥ 4,5:1 sobre blanco
  r.setProperty('--marca-suave', mezcla(principal, '#FFFFFF', 0.88));
  r.setProperty('--acento', acento);
  r.setProperty('--acento-sobre', sobre(acento));
  r.setProperty('--acento-texto', comoTexto(acento));
}
// sobre(c): el de mayor contraste WCAG entre #FFFFFF y #17150F
// comoTexto(c): mezcla c con la tinta en pasos de 5 % hasta 4,5:1
